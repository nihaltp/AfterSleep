AfterSleep is a Kotlin + Jetpack Compose Android app for delayed media playback control.

Set a timer to automatically pause or resume media playback while you sleep. The app runs a foreground service for reliable timers and uses Notification listener support for active session detection.

<h3>Highlights</h3>

<ul>
  <li>Dark-only Material 3 UI</li>
  <li>MediaSessionManager and MediaController based playback control</li>
  <li>Foreground service for reliable timers</li>
  <li>Notification listener support for active session detection</li>
  <li>MVVM architecture with StateFlow and coroutines</li>
  <li>Settings for default delay, stop-after, dim screen, monochrome mode, and fallback behavior</li>
</ul>
